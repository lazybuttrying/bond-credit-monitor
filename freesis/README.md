# 회사채 데이터 수집 방안, FreeSIS (금융투자협회 종합통계)

작성 2026-11-04. 준 curl 1건을 해독하고, FreeSIS 채권 서비스 17개를 전수 확인하고, 수집기를 만들어서 실데이터로 검증한 결과다.

## 결론

- FreeSIS는 인증 없이 호출되는 공개 통계 API다.
- 세션 쿠키가 없어도 같은 데이터가 나온다. 실측으로 확인했다.
- 회사채 집계 데이터는 여기서 일 단위로 수집할 수 있다.
- 종목별 체결 틱은 여기서 못 구한다.
- 그래서 역할은 둘로 나뉜다.
- 시장 단위 시리즈는 FreeSIS로 살리고, 발행자 단위 스프레드는 기존 틱 피드가 맡는다.

## 준 curl이 실제로 가져오는 것

- 서비스는 STATBND0100000280, 이름은 대차거래내역이다.
- OBJ_NM 끝의 BO는 채권 구분이다.
- 필드는 종목명, 종목코드, 체결금액, 상환금액, 잔고금액 순서다.
- 단위는 백만원이다. tmpV40이 단위 나누수다.
- 2026-11-02 응답은 295종목이다.
- 구성은 국고채와 분리채권, 통안증권, 국민주택채권, 은행채, 특수채뿐이다.
- 일반 회사채는 0종목이다.
- 대차 잔고 합계는 188.5조원이다.
- 회사채 수집이 목적이면 이 테이블은 본진이 아니다.
- 참고용으로만 수집기에 옵션으로 넣어 뒀다.

## 파라미터 해독

- 호출 주소는 POST https://freesis.kofia.or.kr/meta/getMetaDataList.do 이다.
- OBJ_NM 규칙은 서비스 ID에 BO를 붙인 형태다. 채권 서비스 전부 같다.
- tmpV1은 자료주기다. D는 일간, M은 월간, Y는 연간이다.
- tmpV45는 시작일, tmpV46은 종료일이다.
- 시계열 테이블은 tmpV46이 비어 있으면 빈 응답을 준다. 종료일을 반드시 채워야 한다.
- 스냅샷 테이블은 tmpV45 하루치만 본다.
- tmpV40은 표시 단위 나누수다. 1000000이면 백만원 단위다.
- tmpV40을 1로 두면 큰 숫자가 ###### 로 마스킹된다. 실측했다. 백만원 고정이 맞다.
- tmpV41은 값을 바꿔도 응답이 같다. 용도 미확인이라 원본 값 1을 유지한다.
- 표 정의는 POST /meta/getSrvData.do 로 받을 수 있다.
- 요청 본문에 strSvrId로 서비스 ID를 넣으면 헤더 이름, 검색 변수, 단위, 유의사항이 전부 온다.
- 새 표를 붙일 때는 화면을 뒤지지 말고 이 메타데이터부터 받으면 된다.

## 수집 대상, 회사채가 있는 표 6개

- 채권거래현황 STATBND0100000250
  - 날짜별, 채권 종류별 거래량과 거래대금과 거래건수다.
  - 회사채 열이 따로 있다.
  - 장외와 장내를 tmpV75로 나눈다. 1이 장외, 2가 장내다.
  - 범위 호출 한 번에 여러 날짜가 온다.
- 잔존기간별거래현황 STATBND0100000260
  - 잔존기간 구간별 거래다. 회사채 열이 있다.
  - 날짜 열이 없어서 호출 구간 전체를 합산한 값이 온다.
- 투자자별거래현황 장외 STATBND0100000270
  - 매매유형과 채권 종류별, 투자자 유형별 거래대금이다.
  - 투자자는 증권사간, 은행, 자산운용 공모와 사모, 보험, 종금, 기금공제, 외국인, 국가와 지자체, 기타법인, 개인으로 나뉜다.
  - 잔존기간 변수를 00으로 채워야 값이 나온다. 비우면 전부 0이 온다.
  - 틱 피드에는 투자자 유형이 없어서 이 표만 주는 정보다.
- 발행통계 STATBND0100000230
  - 채권 종류별 발행액, 상환액, 순발행액, 잔액, 종목수다.
  - 회사채 행이 있다. 하루 단위 스냅샷 호출이다.
- 만기통계 STATBND0100000240
  - 날짜별, 채권 종류별 만기도래 금액이다.
  - 주말 날짜도 행이 있다. 만기는 달력 날짜 기준이다.
- 최종호가수익률 STATBND0100000010
  - 국고채 잔존기간별 수익률과 회사채 무보증 3년 AA-와 BBB- 수익률이 하루 스냅샷으로 온다.
  - AA-에서 국고 3년을 빼면 모니터의 대표 스프레드와 같은 시리즈가 된다.

이력 범위도 확인했다.

- 2015-01-05 데이터가 정상으로 온다.
- 표마다 시작일은 2010-01-01 전후로 등록돼 있다.
- 과거 백필도 같은 수집기로 된다.

## 수집기
